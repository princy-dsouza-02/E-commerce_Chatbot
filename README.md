# E-Commerce Semantic Search Chatbot

An NLP-based e-commerce customer-support chatbot using semantic search.

## Technologies

- Python
- Sentence Transformers
- FAISS
- Streamlit
- Entity Extraction

## Dataset

Bitext Retail E-commerce Chatbot Dataset.

## Supported Tasks

- Order tracking
- Product returns
- Payment issues
- Refund status

## System Pipeline

Customer Query
→ Sentence Embedding
→ FAISS Semantic Search
→ Intent Detection
→ Category Detection
→ Entity Extraction
→ Response Generation
